# 🗳️ CampusVote – College Campus Voting System

A web-based **College Campus Voting System** designed to make college elections simple, digital, and efficient.

## 📌 About

CampusVote allows students to **register, log in, view elections, vote for candidates, and view results** through an easy-to-use web interface. Administrators can manage elections, candidates, voters, and election activities.

## ✨ Features

- 👤 Student Registration & Login
- 🔐 Duplicate Student ID, Email & Mobile Validation
- 🗳️ Online Voting
- 📊 Election Results
- 🛠️ Admin Dashboard
- 👥 Candidate & Voter Management
- 📢 Election Announcements
- 📝 Audit Log
- 📱 Responsive Design

## 🛠️ Technologies

**HTML5 • CSS3 • JavaScript • LocalStorage**

## 🔄 How It Works

**Register → Login → View Election → Select Candidate → Cast Vote → View Results**

## 🔒 Security

The system prevents duplicate registration using **Student ID, Email, and Mobile Number**.  
For production deployment, backend authentication, database security, OTP verification, password hashing, and secure vote storage can be integrated.

## 🎯 Objective

To provide a **fast, transparent, paperless, and user-friendly digital voting system** for college campus elections.
